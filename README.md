# 🔐 Sobre o projeto

O **Sistema de Login** é uma aplicação desenvolvida com o objetivo de realizar o **cadastro e autenticação de usuários**, permitindo controlar o acesso ao sistema através de credenciais.

O projeto será desenvolvido utilizando **Java** como linguagem principal e **Java Swing** para a construção da interface gráfica.

A aplicação permitirá que usuários realizem seu cadastro e posteriormente utilizem suas credenciais para acessar o sistema.

O sistema contará com funcionalidades relacionadas ao gerenciamento de usuários, validação de credenciais e controle de acesso.

O projeto está sendo desenvolvido como parte do **Projeto Final da disciplina de Programação Orientada a Objetos (POO) — 2026.2**.

# 🏢 Sobre o Sistema de Login

O Sistema de Login foi desenvolvido com a ideia de criar uma aplicação responsável pelo **gerenciamento de acesso de usuários**.

O sistema busca proporcionar uma experiência simples e organizada para que o usuário possa realizar seu cadastro e posteriormente acessar a aplicação através de suas credenciais.

A interface gráfica será desenvolvida utilizando **Java Swing**, permitindo a criação das telas e componentes necessários para a interação com o usuário.

### 🎯 Missão

Desenvolver uma solução de autenticação funcional e organizada, facilitando o gerenciamento de usuários e o controle de acesso à aplicação.

### 🔭 Visão

Criar um sistema de login estruturado que possa servir como base para aplicações que necessitem de autenticação e gerenciamento de usuários.
